## Corrections and limitations

- Saffron Origins currently sells apparel. The previous dossier described Kashmiri saffron and batch provenance. That description is not consistent with the current site and is not published. The case study and demo now cover apparel option selection and cart state.
- Janus currently presents content production and review queues. The public summary and demo focus on queued work; the former outbound lead-dispatch description is not repeated.
- Knittire's original homepage was captured; the live customiser also exists. The sandbox uses a newly authored procedural garment model, not downloaded client production geometry.
- Hisaab and SafeSpot public captures contain outcome or evaluation claims that this audit does not establish. Those captures were not selected for the website. The pages use fictional reconstruction previews instead.
- Growth records are credited as creative/growth collaborations. Missing original creative assets are not replaced with purported campaign screenshots: their previews are captured from labelled guided reconstructions.
- Numerical claims from the previous dataset, including ROAS, conversion lifts, revenue, timing and claimed statistical confidence, are excluded from public editorial copy.

## Asset production

Demo preview images are direct screenshots of the implemented local demos. Social images pair each project's title and description with a project capture or clearly labelled demonstration preview. No Instagram footage, soundtrack or reference screenshot is published as a website asset.
